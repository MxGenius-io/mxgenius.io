# MxGenius Sensor Bridge 0.1.0-alpha.19

This build begins the named Alpha series and aligns the package identity with the Meta Alpha release channel.

- Preserves the proven FLIR ONE discovery, permission, streaming, and native VR lifecycle from `0.1.0-poc.18`.
- Adds the versioned spatial target and deliberate snapshot-scan contracts used by model awareness.
- Carries authenticated local bridge metadata for thermal, headset snapshot, and remote-witness capabilities.
- Keeps model analysis operator-triggered; the headset does not send continuous camera frames to the model.
- Reserves customer witness transport as an explicit, consent-driven session rather than background capture.

# Meta store assets

`manifest.json` is the local source of truth for every file in this folder. It records the exact Meta Developer Dashboard field, required dimensions, pixel format, and SHA-256 checksum.

For the current draft submission, open **App submissions > v1 > App metadata > Assets > Cover art > Landscape** and upload `cover-landscape-2560x1440.png`. The similarly named source file is retained for future edits and is not the upload artifact.

Changing these dashboard assets does not require a new APK and does not submit the public Store draft.

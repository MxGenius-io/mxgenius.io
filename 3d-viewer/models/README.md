Place bundled .glb, .gltf, .fbx, or .obj model files here and register them in
../models.json.

Models marked `quickAccess: true` are the deliberately small top dropdown set.
Models marked `quickAccess: false` remain available through the Models drawer.
Public reference catalogs are loaded separately and never enter quick access.

File naming tip (MilVerse convention):
  SM_Truck_Base_v1.fbx → displays as "Truck Base v1"
